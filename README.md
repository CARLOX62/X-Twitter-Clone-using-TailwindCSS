# X Clone

A Twitter clone built using Tailwind CSS, featuring a responsive design that mimics the look and feel of the X (formerly Twitter) platform.

## Description

This project is a static web application that replicates the user interface of Twitter (now X). It includes a sidebar for navigation, a main feed for posts, and a right panel with search, trending topics, and user suggestions. The design is fully responsive and uses Tailwind CSS for styling.

## Features

- **Responsive Design**: Works seamlessly on desktop and mobile devices.
- **Sidebar Navigation**: Includes icons and labels for Home, Explore, Notifications, Grok, Lists, Bookmarks, Communities, Premium, Profile, and More.
- **Main Feed**: Displays sample posts with user profiles, timestamps, content, and interaction buttons (reply, repost, like, view stats).
- **Right Panel**: Features a search bar, Premium subscription prompt, Today's News, Trending topics, and "Who to Follow" suggestions.
- **Interactive Elements**: Hover effects, buttons, and icons using Material Symbols.
- **Dark Theme**: Styled with a black background and white text, consistent with X's branding.

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   cd x-clone
   ```

2. Install dependencies:
   ```
   npm install
   ```

## Usage

To run the development server:
```
npm run dev
```

To build the CSS:
```
npm run build
```

Open `index.html` in your browser to view the application.

## Technologies Used

- **HTML**: Structure of the web page.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **Vite**: Build tool and development server.
- **Material Symbols**: Icon library for UI elements.
