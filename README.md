# 🐦 X Clone (Twitter UI Clone)

A modern, responsive Twitter (X) UI clone built with **TailwindCSS** and **Vite**.  
The design closely mimics the interface of X (formerly Twitter) and includes features like side navigation, feed layout, right utility panel, and interactive hover elements.

---

## 🚀 Live Demo  
🔗 **View Project:** https://carlox62.github.io/X-Twitter-Clone-using-TailwindCSS/

---

## 📌 Features

- 📱 **Fully Responsive UI**
- 🧭 **Sidebar Navigation** (Home, Explore, Notifications, Lists, Grok, Profile & more)
- 📝 **Main Feed Layout** with Tweets, avatars, timestamps & action buttons
- 🔍 **Right Panel** with search bar, trending topics & follow suggestions
- 🎨 **Dark Theme UI**
- ✨ **Hover effects & Material Symbols icons**

## ⚙️ Installation & Setup

1️⃣ Clone the repository:

```sh
git clone <repository-url>
cd x-clone
```

2️⃣ Install dependencies:

```sh
npm install
```

3️⃣ Start development server:

```sh
npm run dev
```

4️⃣ Build CSS for production:

```sh
npm run build
```

Then open `index.html` in the browser to view the UI.
